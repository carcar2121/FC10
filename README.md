FC10 | The Football History Encyclopedia ⚽
Football has a history. FC10 keeps it alive.
FC10 is a digital football encyclopedia dedicated to preserving, organizing, and exploring the history of football.
The project brings together historical champions, individual awards, competitions, legendary players, clubs, records, statistics, and historical narratives in one place.
More than a database of winners, FC10 aims to become a comprehensive archive where football fans can discover not only who won, but also the stories, people, and events behind every historic achievement.

⸻

🌍 Project Overview
FC10 is designed as a modern, accessible, and expandable football history platform.
Visitors can explore historical records, search for winners, discover important football achievements, and read articles about memorable seasons, competitions, and legendary players.
The long-term vision is to build an interconnected football encyclopedia, where articles, player profiles, clubs, and competitions are linked together.
✨ Main Features
🏆 Historical Palmarès
Explore four major football collections:
Ballon d’Or: Historical winners of the most prestigious individual football award.
European Golden Shoe: Top goalscorers recognized by the European Golden Shoe award.
UEFA Champions League: Historical winners of Europe’s most important club competition, including the European Cup era.
Liga MX: Historical champions of Mexican professional football.
Features include:
Chronological historical records.
Search by year, player, or team.
Organized collection categories.
Individual historical record pages.
Men’s and women’s Ballon d’Or sections as verified data becomes available.
📖 Historical Articles
FC10 aims to go beyond statistics by providing detailed historical narratives.
Articles can include:
Historical context.
Important events and decisive moments.
Players and teams involved.
Statistics and achievements.
Historical photographs.
References and sources.
Related articles.
Articles are designed to use Markdown, allowing content to be organized and updated without modifying the main application code.
🔗 Connected Football Encyclopedia
The long-term architecture supports interconnected pages for:
Football players.
Football clubs.
Competitions.
Historical seasons.
Related articles.
This structure will allow visitors to navigate between people, teams, competitions, and historical events.
📊 Records & Statistics
A dedicated section for exploring historical football data through statistics, comparisons, tables, and visualizations.
All statistics should be calculated from available and verified records.
🤝 Community
FC10 encourages football fans to suggest historical stories, important matches, legendary players, and events worth documenting.
Community suggestions are collected through an external submission form.

💻 Installation & Local Setup
To run FC10 locally, follow these steps.
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
2. Enter the project directory
cd FC10
3. Install dependencies
py -m pip install -r requirements.txt
4. Run the application
py -m streamlit run app.py
Streamlit will open the application in your default browser.

📊 Database
FC10 initially uses a structured dataset containing four historical collections:
Ballon d’Or winners.
UEFA Champions League winners.
European Golden Shoe winners.
Liga MX champions.
The database is available in two formats:
CSV for application data processing.
XLSX for spreadsheet consultation and manual administration.
The initial dataset covers 2000–2026.
Historical information must be verified before publication. Missing records should never be replaced with invented information.

📰 Historical Content & Editorial Principles
FC10 aims to maintain high standards of historical accuracy.
The project follows these principles:
Use reliable historical sources.
Verify important dates, winners, and statistics.
Write original historical narratives.
Include references for historical articles.
Distinguish confirmed facts from interpretation.
Clearly identify information that has not yet been verified.
The objective is not simply to collect football statistics, but to preserve the context behind the history of the sport.
